# Layout Recipes

Recipes combine the lower-level layout primitives into structures you can drop into an application and customize.

## Dashboard shell

Use a dashboard shell for navigation-heavy products with persistent tools and a focused content region.

## Documentation shell

Use a documentation shell when readers need package navigation alongside long-form content.

## Settings shell

Use a settings shell to group related forms while keeping the current section visible.
